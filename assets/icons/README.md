# Icons Directory

Place custom SVG icons here if needed.

## Currently Using
The application uses Font Awesome 6.4.0 for all icons via CDN.

## Adding Custom Icons
If you want to add custom SVG icons:

1. Place `.svg` files here
2. Reference them in HTML: `<img src="./assets/icons/your-icon.svg" alt="Icon">`
3. Or use as background images in CSS

## Icon Naming Convention
- Use lowercase
- Use hyphens for spaces
- Be descriptive

Examples:
- `resume-icon.svg`
- `download-pdf.svg`
- `template-preview.svg`
